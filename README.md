# Tkinter GUI Prototype

A Python GUI project built using **Tkinter** and **ttk**.

### Features
- Basic widgets: Labels, Buttons, Entry, Text
- Selection widgets: Listbox, Checkbutton, Radiobutton
- Layout managers: Pack, Grid, Place
- Canvas and Scrollbars
- Menus and Dialog Boxes
- Event and Keyboard Handling
- Multiple Windows (Toplevel)
- Themed Widgets: Progressbar, Treeview, Notebook
- Images and Clipboard Handling

### Technologies Used
- Python
- Tkinter
- ttk

### Run Locally

```bash
python main.py
```

**Purpose:** Learning and demonstrating Python Tkinter GUI components and their functionality.
